# Site de vente en ligne

Projet réalisé dans le cadre du cours **Développement avancé d'application web** (Hénallux, Bachelier en Développement d'applications).

## Description

Ce projet consiste à concevoir et développer un **site web de vente en ligne** : présentation d'un catalogue de produits, gestion d'un panier et passage de commande.
